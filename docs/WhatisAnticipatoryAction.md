# What is Anticipatory Action?

* An alert can use a forecast to tell us that something bad, like a drought, is likely to happen

* But just having part of a map flagged with red doesnt tell us what we want to do

### What is the value of doing more than Alerts?

* Anticipatory Action for Disasters is the next step
* We work together to decide **BEFOREHAND**:
	* How we would work together to act before the disaster strikes 
	* How we would **pay for the actions**
* Then, the forecast triggers funded coordinated action before the disaster

* For Anticipatory Action, we need to work out the challenging questions together beforehand
